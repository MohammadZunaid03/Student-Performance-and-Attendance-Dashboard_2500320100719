# P16 — Automated Testing and Validation

Create pytest/unittest tests for duplicate keys, missing required IDs, valid marks, valid attendance, grade calculations, pass/fail, ranking/ties, absent/missing marks, Python-vs-Oracle totals, dimension references and dashboard KPI calculations.

Print PASS/FAIL and save Test Case ID, Description, Input, Expected Result, Actual Result and Status to `reports/test_results.csv`. Include live-Oracle integration tests and isolated unit tests. Do not mark unexecuted tests as passed; identify skipped/not-verified tests honestly.

**Output:** `tests/test_pipeline.py`, `reports/test_results.csv`.
