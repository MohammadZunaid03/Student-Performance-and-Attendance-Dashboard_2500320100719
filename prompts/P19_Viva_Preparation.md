# P19 — Code Explanation and Viva

Act as a strict university project evaluator. Explain the actual repository code line by line in simple English suitable for a B.Tech second-year student. Cover architecture, Python, Pandas/NumPy, Oracle schema, SQL, PL/SQL, Power BI relationships, DAX, Excel validation, testing and business insights. Do not explain imagined code as if implemented.

Prepare 40 questions: Python 8; Pandas/NumPy 5; Oracle SQL 7; PL/SQL 5; Power BI/DAX 7; data modelling 4; architecture/business insights 4.

In interactive practice, ask one question at a time, wait for the answer, evaluate it and explain corrections. Do not reveal all answers before attempts.

**Output:** `docs/04_Viva_Preparation.md` and interactive viva practice.
