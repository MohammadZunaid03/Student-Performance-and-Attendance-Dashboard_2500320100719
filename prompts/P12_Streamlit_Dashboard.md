# P12 — Streamlit Dashboard

Build an interactive Streamlit dashboard using cleaned project data.

Sections: Overview; Student Performance; Attendance Analysis; Subject Analysis; Student Ranking.

Four KPI cards: Total Students, Average Marks, Overall Pass Percentage, Average Attendance.

Filters: Department, Semester, Section, Subject, Academic Year.

Charts/tables: pass/fail distribution, subject performance, attendance trends, top 10 students, low-attendance list. All KPIs and visuals must respond to filters. Add filtered-data downloads, source caption and refresh timestamp. Handle empty selections and missing data. Avoid exposing sensitive student information publicly. Provide requirements and run command.

**Output:** `app/streamlit_app.py` and updated `requirements.txt`.
