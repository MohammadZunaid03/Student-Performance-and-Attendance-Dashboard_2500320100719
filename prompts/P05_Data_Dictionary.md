# P5 — Data Dictionary

Inspect the actual CSV headers and sample rows produced in P4. Create a data dictionary for every dataset with: Table, Column, Data Type, Description, Example, Validation Rule and Nullable.

Identify primary keys, foreign keys, uniqueness, required fields, valid ranges and business rules. Examples: attendance percentage 0–100; marks do not exceed maximum marks; present classes do not exceed total classes.

Do not invent columns, examples or data types. If source CSVs are not present, request them instead of fabricating a dictionary. Provide a table suitable for Excel and a generated workbook.

**Output:** `docs/Data_Dictionary.xlsx` and `docs/Data_Dictionary.md`.
