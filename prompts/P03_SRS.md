# P3 — Software Requirements Specification

Create an SRS for Student Performance and Attendance Dashboard.

Include: introduction, purpose, scope, overall description, user categories (Administrator, Faculty, Academic Coordinator), assumptions, constraints and data privacy.

Functional requirements table: ID, requirement, priority, verification method. Use FR1 onward. Cover student records, marks, attendance, grade calculation, pass/fail classification, ranking, subject analysis, low-attendance identification and reports.

Non-functional requirements table: ID, requirement, measurable metric/target and verification. Use NFR1 onward. Include usability, reliability, performance, maintainability, security and data integrity.

Add data requirements and testable acceptance criteria. Requirements must be measurable and consistent with the project scope. Do not claim authentication or deployment unless planned.

**Output:** `docs/02_SRS.md`.
