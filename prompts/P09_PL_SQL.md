# P9 — Oracle PL/SQL Implementation

Develop executable Oracle PL/SQL for:
1. Grade calculation function.
2. Student percentage function.
3. Pass/fail classification procedure.
4. Student ranking procedure.
5. Low-attendance identification procedure.
6. Student academic-summary procedure.
7. Exception handling and suitable cursors.

Define grading boundaries and attendance threshold in one documented configuration source. Do not duplicate inconsistent business rules. Handle absent students, missing marks and tied ranks explicitly. Avoid unexpected source-data updates.

Provide scripts, prerequisites, test inputs, expected outputs and simple explanations. Clearly mark anything not actually executed against Oracle.

**Output:** `sql/plsql/` and `docs/PLSQL_Guide.md`.
