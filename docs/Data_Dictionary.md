# Data Dictionary

This dictionary is based on the committed raw CSV headers in data/raw. Types describe intended logical types; blank values are permitted only where specified.

## students.csv
| Column | Type | Nullable | Description | Validation |
|---|---|---|---|---|
| Student_ID | string | No | Stable student identifier | Unique, non-empty |
| Student_Name | string | No | Fictional student display name | Trim whitespace; non-empty |
| Department | string | Yes in raw | Department code | Standardised; UNKNOWN allowed after cleaning |
| Semester | integer | No | Semester number | Positive integer |
| Section | string | No | Class section | Non-empty |

## subjects.csv
| Column | Type | Nullable | Description | Validation |
|---|---|---|---|---|
| Subject_ID | string | No | Subject identifier | Unique, non-empty |
| Subject_Name | string | No | Subject title | Non-empty |
| Subject_Code | string | No | Subject code | Unique, non-empty |
| Maximum_Marks | integer | No | Maximum combined score | Positive |
| Passing_Marks | integer | No | Minimum passing score | 0 to Maximum_Marks |

## marks.csv
| Column | Type | Nullable | Description | Validation |
|---|---|---|---|---|
| Marks_ID | string | No | Source marks-row identifier | Unique after duplicate handling |
| Student_ID | string | No | Student reference | Must exist in students |
| Subject_ID | string | No | Subject reference | Must exist in subjects |
| Internal_Marks | integer | Yes | Internal assessment score | 0–40 in synthetic source design |
| External_Marks | integer | Yes | External assessment score | 0–60 in synthetic source design |
| Total_Marks | integer | Yes | Combined marks | Recomputed from valid components; 0–100 |
| Grade | string | Yes | Derived grade | Generated by configured grade policy |
| Result | string | Yes | Derived result | PASS, FAIL, ABSENT or MISSING |
| Record_Status | enum | No | Source marks status | PRESENT, ABSENT or MISSING |

## attendance.csv
| Column | Type | Nullable | Description | Validation |
|---|---|---|---|---|
| Attendance_ID | string | No | Source attendance-row identifier | Unique after duplicate handling |
| Student_ID | string | No | Student reference | Must exist in students |
| Subject_ID | string | No | Subject reference | Must exist in subjects |
| Total_Classes | integer | No | Number of conducted classes | Greater than zero |
| Present_Classes | integer | No | Number of attended classes | 0 to Total_Classes |
| Absent_Classes | integer | No | Number of missed classes | Recomputed as Total minus Present |
| Attendance_Percentage | decimal | No | Attendance rate | Recomputed as Present / Total × 100 |

## academic_terms.csv
| Column | Type | Nullable | Description | Validation |
|---|---|---|---|---|
| Term_ID | string | No | Academic-term identifier | Unique, non-empty |
| Academic_Year | string | No | Academic-year label | Non-empty |
| Semester | string | No | Semester grouping label | Non-empty |
| Start_Date | date (ISO 8601) | No | Term start date | Valid date |
| End_Date | date (ISO 8601) | No | Term end date | On or after Start_Date |

## Keys and relationships
- Primary keys: students.Student_ID; subjects.Subject_ID; marks.Marks_ID; attendance.Attendance_ID; academic_terms.Term_ID.
- Logical marks grain: one row per Student_ID + Subject_ID + academic term.
- Logical attendance grain: one row per Student_ID + Subject_ID + academic term.
- Foreign keys: marks.Student_ID → students.Student_ID; marks.Subject_ID → subjects.Subject_ID; attendance.Student_ID → students.Student_ID; attendance.Subject_ID → subjects.Subject_ID.
- The current synthetic sample has one academic term. The term key will be added to fact records in the warehouse-loading phase.

## Synthetic policy notes
The source generator uses a synthetic 40-mark internal component, 60-mark external component and 40/100 passing mark. These are demonstration values, not confirmed institutional rules. Grade boundaries and the attendance threshold must remain configurable pending confirmation.
